All configuration is supplied through environment variables.
The project reads them at runtime only: no variable needed by the server is exposed to the browser via a `VITE_` prefix.

<Warning>
Never commit `.env` to version control. The file is gitignored by default. Never prefix secrets with `VITE_`; Vite exposes those values to client bundles.
</Warning>

## Database

| Variable | Required | Default / example | Allowed range | Purpose |
| --- | --- | --- | --- | --- |
| `DB_HOST` | Yes | `127.0.0.1` | Valid hostname or IP | MySQL server host |
| `DB_PORT` | Yes | `3306` | `1` to `65535` | MySQL server port |
| `DB_NAME` | Yes | `loa_vrtt` | Alphanumeric and underscores only | Database name |
| `DB_USER` | Yes | `loa_vrtt` | Alphanumeric and underscores only | Limited application user (SELECT, INSERT, UPDATE, DELETE only) |
| `DB_PASSWORD` | Yes | Generated by `db:setup` | Minimum 20 characters | Application user password; generated during setup and never printed |
| `DB_CONNECTION_LIMIT` | No | `5` | `1` to `100` | Max connections in the pool |
| `DB_MAX_IDLE` | No | `5` | `0` to `100` | Max idle connections allowed |
| `DB_IDLE_TIMEOUT_MS` | No | `30000` | `1000` to `300000` | Idle connection timeout in milliseconds |
| `DB_QUEUE_LIMIT` | No | `20` | `0` to `10000` | Max queued connection requests |
| `DB_SLOW_QUERY_MS` | No | `1000` | `50` to `60000` | Threshold in milliseconds for logging slow queries |

## Google OAuth and Gmail

| Variable | Required | Default / example | Purpose |
| --- | --- | --- | --- |
| `GOOGLE_CLIENT_ID` | Yes for Google features | Empty | Institutional OAuth client ID for Google sign-in and Gmail |
| `GOOGLE_CLIENT_SECRET` | Yes for Google features | Empty | Institutional OAuth client secret |
| `GOOGLE_EXTERNAL_CLIENT_ID` | No | Empty | Separate OAuth client for former employees and verifiers on `/coe`; falls back to `GOOGLE_CLIENT_ID` if unset |
| `GOOGLE_EXTERNAL_CLIENT_SECRET` | No | Empty | Secret for the external consent screen client |
| `GOOGLE_REDIRECT_URI` | Yes for Gmail | `http://localhost:8080/api/gmail/callback` | Gmail authorization callback URI; must be registered on the OAuth client |
| `GOOGLE_SIGNIN_REDIRECT_URI` | Yes for Google sign-in | `http://localhost:8080/api/auth/google/callback` | Google sign-in callback URI; must be registered on the OAuth client |
| `GOOGLE_SENDER_EMAIL` | Yes for email sending | `hrdo.desk@lyceumalabang.edu.ph` | Gmail account authorized to send system mail |
| `GOOGLE_REFRESH_TOKEN` | Yes for email sending | Empty | OAuth refresh token for the sender account; saved by the `/api/gmail/connect` flow |

<Note>
The `/api/gmail/connect` endpoint is available only on localhost in non-production environments. The callback rejects a different Google account and saves only the refresh token.
</Note>

## Google Sheets and attendance

| Variable | Required | Default / example | Purpose |
| --- | --- | --- | --- |
| `GOOGLE_SHEETS_SERVICE_ACCOUNT_JSON` | Yes for attendance sync | Empty | Service account JSON key for Google Sheets API access |
| `LATE_ABSENCES_WEBHOOK_SECRET` | Yes for webhook | Empty | Shared secret sent in the `x-webhook-secret` header for `/api/sheets/webhook` |
| `LATE_ABSENCES_NON_TEACHING_SPREADSHEET_ID` | Yes for sync | Empty | Google Sheets ID for non-teaching staff |
| `LATE_ABSENCES_COLLEGE_SPREADSHEET_ID` | Yes for sync | Empty | Google Sheets ID for college staff |
| `LATE_ABSENCES_BASIC_ED_SPREADSHEET_ID` | Yes for sync | Empty | Google Sheets ID for basic education staff |

<Note>
The codebase also accepts `LATE_ABSENCES_EXCLUDED_USER_EMAILS` as an optional comma-separated list of email addresses to exclude from sync processing.
</Note>

## Setup-only

These variables are used only by the `scripts/setup-db.mjs` script and are not written to `.env`.

| Variable | Required | Default | Purpose |
| --- | --- | --- | --- |
| `MYSQL_ROOT_USER` | No | `root` | MySQL root username for `db:setup` |
| `MYSQL_ROOT_PASSWORD` | No | Empty | MySQL root password for `db:setup` |
