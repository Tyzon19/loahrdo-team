The LOA HRDO systems are a full-stack TypeScript application built with React 19, TanStack Start, and Vite 8. The server runs on Node.js 20+ and connects to MySQL or MariaDB via mysql2.

## Runtime requirements

| Requirement | Recommended value |
| --- | --- |
| Node.js | 20 or newer |
| Package manager | npm |
| Database | MySQL or MariaDB (InnoDB, utf8mb4) |
| Local database stack | Laragon (Windows) or equivalent |
| Browser | Current Chrome, Edge, Firefox, or Safari |
| Device | Desktop, tablet, or mobile with responsive layout |
| Network | HTTPS in production |

## Build tooling notes

### Vite configuration

`vite.config.ts` configures:

- `tanstackStart` plugin with custom SSR error wrapper entry (`server.ts`)
- `@vitejs/plugin-react` for React Fast Refresh
- `@tailwindcss/vite` for Tailwind CSS processing
- `vite-tsconfig-paths` for `@/` alias resolution
- Dev server on port `8080` with `strictPort: true`
- Allowed hosts: `localhost`, `127.0.0.1`, `*.trycloudflare.com`
- File watcher ignores `.output/**` and `.nitro/**` to avoid lock errors

### Nitro

TanStack Start uses `nitro` (`3.0.260603-beta`) as its server engine. The custom `server.ts` entry wraps the default server entry to normalize catastrophic SSR errors and inject security headers on every response.

### TypeScript

The project uses TypeScript `^5.8.3` with path mapping (`@/*` -> `src/*`) and strict mode. All server functions are typed with Zod schemas and shared types in `src/lib/types.ts`.
